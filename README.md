# Supply Chain Decision Hub POC

A self-contained static proof of concept for reviewing supply-chain fulfillment decisions, what-if conditions, and historical alternatives.

## Run locally

Open `index.html` in a modern browser. No build step, server, or external dependency is required.

## Demo scope

All values are static mock data for demonstration purposes. The POC includes interactive workspace navigation, what-if presets, and client-side PDF export.

## GitHub Pages

The site is Pages-compatible because `index.html` is at the repository root. After enabling Pages from the `main` branch, the POC is served at the repository's GitHub Pages URL.
